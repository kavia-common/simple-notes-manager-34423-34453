# Ocean Notes - Simple Notes Manager (Astro)

A minimal notes application built with Astro that runs entirely in the browser. Notes are persisted in localStorage.

Features:
- Two-pane layout: sidebar list + editor
- Create, edit, delete notes
- Search by title/content
- Optional Markdown-like preview (basic)
- Responsive: collapsible sidebar on small screens
- Ocean Professional theme

Getting started:
- npm install
- npm run dev
- Open http://localhost:3000

Data:
- Stored under localStorage key: notes_v1

Keyboard shortcuts:
- Ctrl/Cmd+N: New note
- Delete: Delete current note
- Ctrl/Cmd+F: Focus search
